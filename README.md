# CustomShade — কাস্টম নোটিফিকেশন + কন্ট্রোল সেন্টার

- স্ক্রিনের উপরের **বাম অর্ধেক** থেকে নিচে টানলে → নোটিফিকেশন প্যানেল
- স্ক্রিনের উপরের **ডান অর্ধেক** থেকে নিচে টানলে → কন্ট্রোল সেন্টার (৩য় ছবির স্টাইল)

## GitHub দিয়ে APK বানানো
1. GitHub-এ নতুন repository খুলুন।
2. এই ফোল্ডারের সব ফাইল (`.github` ফোল্ডারসহ) repository-তে আপলোড/পুশ করুন (branch: `main`)।
3. **Actions** ট্যাবে `Build APK` চলবে (না চললে "Run workflow" চাপুন)।
4. শেষ হলে run-এর নিচে **Artifacts → CustomShade-debug-apk** ডাউনলোড করুন, জিপ খুলে APK ইনস্টল করুন।

## ইনস্টলের পর
অ্যাপ খুলে ৪টি ধাপ করুন (Accessibility সবচেয়ে জরুরি)। বিস্তারিত অ্যাপের ভিতরেই লেখা আছে।

## সীমাবদ্ধতা
- এটি আসল SystemUI বদলায় না; উপরে অদৃশ্য ওভারলে স্ট্রিপ বসিয়ে সোয়াইপ ধরে নিজের প্যানেল দেখায়।
- Wi-Fi / মোবাইল ডেটা / ব্লুটুথ / এয়ারপ্লেন সরাসরি অন-অফ করা যায় না (Android নিষেধ করে) — ট্যাপ করলে সংশ্লিষ্ট সেটিংস প্যানেল খোলে।
- আইকনগুলো ইমোজি/টেক্সট; চাইলে পরে ভেক্টর আইকন বসানো যাবে।
